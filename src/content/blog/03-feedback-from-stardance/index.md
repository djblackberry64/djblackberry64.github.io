Ok so now that Stardance has ended, I wanted to talk about my projects. More specifically, the feedback I got for the projects.

First, the stellar programming fundamentals course. To start off, I would be exaggerating if I said that there was only good or only bad feedback for this project. Most were positive, some neutral and others justfyingly frustrated (and some missed the point of the project). Nonetheless, I'm grateful for the feedback I got for this project as this allowed me to see where the biggest potential lies: namely interacitivity and more to the point explanations in some areas.

Secondly, we're talking about the Space Tutorial Java. It was a different story here. Nearly all feedback was positive, with the only remarks being that people wished for more content and - like with the previous project - more interactivity (videos, code editors). This feedback was a little different for me, not only because this was a short project compared to the other one (was started in summer of last year) but also because it gave me a little more direction the first project only got from my personal experience.

All in all, the feedback culture on Stardance was overwhelmingly positive. I received feedback that will help me improve my projects and adjust direction where needed. That's not to say there wasn't bad feedback (straight up unconstructive or missing the point) but it's a small price to pay for the real, positive reactions people provided me with.
